Packaging Applications for Krypton APT

KryptonOS uses an authentic Debian `.deb` package structure. Package payloads are distributed as cryptographic JSON archives containing control files, permission manifests, and extracted JavaScript modules:

{ "control": { "Package": "krypton-example", "Version": "1.0.0-release", "Architecture": "amd64", "Maintainer": "Krypton Maintainers <packages@krypton-os.org>", "InstalledSize": 4096, "Section": "utils", "Priority": "optional", "Description": "Example custom sandboxed utility application" }, "files": { "/usr/bin/example": "#!/bin/bash\nexec /usr/lib/krypton-example/index.js \"$@\"\n", "/usr/share/applications/example.desktop": "[Desktop Entry]\nName=Example App\nExec=example\nIcon=⚡\nType=Application\nCategories=Utility;\n", "/usr/lib/krypton-example/index.js": "export function launch(args) { window.story.showToast('Hello from KryptonOS!'); }" } }

Submit your `.deb` packages via Pull Request to the Krypton-Repo repository to be indexed in the official repository catalog.
