Running KryptonOS Locally

You can run the entire KryptonOS sandbox simulator locally using any lightweight HTTP server:

# 1. Clone the repository git clone https://github.com/CreatorPoints/Krypton-OS.git cd Krypton-OS # 2. Run local HTTP server (using Python 3) python3 -m http.server 8080 # Or using Node.js: # npx serve . # 3. Open in your browser: # http://localhost:8080/
