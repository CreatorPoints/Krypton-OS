Engineered For Realism

Every component follows strict Unix standards, POSIX compliance, and authentic Debian packaging paradigms.

🛡️

Two-Layer VFS Overlay Architecture

Immutable baseline web core decoupled from client package storage. Browser hard-refreshes never leak un-upgraded code, preserving authentic sandbox state.

📦

Authentic APT & DPKG Package Engine

True `.deb` archive downloads, cryptographic SHA-256 verification, dependency resolution, `/var/lib/dpkg/status` parsing, and dynamic `/usr/lib/` module extraction.

⚡

Hardware POST, BIOS & GRUB 2.06

Complete American Megatrends Aptio BIOS setup, NVMe/SATA drive mapping, GRUB boot menu with fallback `grub rescue>` shell and Factory Reset recovery.

🖥️

Complete Desktop Application Suite

Sandboxed Quantum Web Browser, Terminal, Upgrade Notes, Scientific Calculator, World Clock & Stopwatch, File Explorer, Task Manager, and System Logs.

💻

POSIX Shell & Core Utilities

Standard GNU Bash emulation supporting pipes (`|`), redirects (`>`, `>>`), logic (`&&`, `;`), parameter expansion, grep, find, lsblk, top, and nano.

🚨

Destructive Sandbox & Recovery

Full destructive command simulation including `sudo rm -rf / --no-preserve-root` with unlinking panic states and live USB recovery mounts.
